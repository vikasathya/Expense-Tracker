# Expense-Tracker

A clean and responsive web-based Expense Tracker that helps users manage their income, expenses, monthly budget, and financial insights in one place.
The application stores transaction data locally in the browser using **LocalStorage**, so your data remains available even after refreshing the page.

## ✨ Features

### 💵 Transaction Management
- Add income transactions
- Add expense transactions
- Edit existing transactions
- Delete transactions
- Select transaction category
- Select transaction date
- Automatic balance calculation

### 📊 Financial Overview
- Total income
- Total expenses
- Current balance
- Savings amount
- Savings rate
- Highest expense
- Top spending category

### 🔎 Search & Filters
- Search transactions by description
- Filter by transaction type
- Filter by category
- Dynamic transaction count

### 💳 Monthly Budget
- Set a monthly budget
- Track monthly spending
- Calculate remaining budget
- Visual budget progress bar
- 80% budget warning
- Over-budget detection
- Overspending amount display

### 📈 Spending Overview
- Current month's total expenses
- Current month's transaction count
- Category-wise spending overview
- Visual spending bars

### 💾 Local Data Storage
- Uses browser LocalStorage
- Transactions remain saved after page refresh
- Monthly budget is also stored locally
- No external database required

### 📱 Responsive Design
- Desktop friendly
- Tablet optimized
- Mobile responsive
- Adaptive transaction layout
